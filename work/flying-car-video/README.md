## Commands

**Install Dependencies**

```console
npm i --loglevel=error
```

**Start Preview**

```console
npm run dev
```

**Render video**

```console
npm run render
```

The preview uses port `3000`. The render script uses `src/index.ts` and the `ChatGPTStickmanSales` composition directly, rather than relying on a stale Studio URL. If the Studio Render button reports that `window.getStaticCompositions` is missing, restart Studio from this project folder with `npm run dev`, then use `npm run render` from a terminal. That command bypasses the stale Studio URL lookup.

**Upgrade Remotion**

```console
npx remotion upgrade
```
